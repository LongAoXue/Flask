✅ Jinja2 常用过滤器 现场演示（可直接套用）

1. 数值过滤器

原始负数：{{ negative_num }}
绝对值：{{ negative_num|abs }}
浮点数：{{ float_num }} → 保留2位：{{ float_num|round(2) }}
转整数：{{ float_num|int }}

2. 字符串过滤器

原始：{{ str_data }}
去空格：{{ str_data|trim }}
大写：{{ str_data|trim|upper }}
首字母大写：{{ str_data|trim|capitalize }}
标题格式：{{ str_data|trim|title }}
替换：{{ "a-b-c"|replace("-", "/") }}
截断文本：{{ long_text|truncate(15) }}

3. 列表过滤器

列表：{{ num_list }}
第一个：{{ num_list|first }}
最后一个：{{ num_list|last }}
长度：{{ num_list|length }}
排序：{{ num_list|sort }}
去重：{{ num_list|unique|list }}
求和：{{ num_list|sum }}
最大值：{{ num_list|max }}
最小值：{{ num_list|min }}
拼接：{{ num_list|join(" → ") }}
反转：{{ num_list|reverse|list }}

4. 字典/对象过滤器

用户：{{ user }}
默认值（空变量）：{{ none_data|default("无数据") }}
取属性：{{ user|attr("name") }}
字典键值对：{{ user|items|list }}

5. HTML 安全过滤器

原始HTML：{{ html_data }}
安全渲染：{{ html_data|safe }}
去除标签：{{ html_data|striptags }}

6. 高级条件过滤

保留偶数：{{ num_list|select("even")|list }}
保留奇数：{{ num_list|select("odd")|list }}
